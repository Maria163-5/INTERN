
# intern

Lightweight workspace containing `agent.py` and project dependencies.

Quick start

- Run the main script locally:

```powershell
py agent.py
```

Pushing to GitHub

1. Create a repository on GitHub named `intern` under your account.
2. Add the remote and push:

```bash
git remote add origin https://github.com/Maria163-5/intern.git
git branch -M main
git push -u origin main
```

Files

- [agent.py](agent.py) — main program file.
- [requirements.txt](requirements.txt) — Python dependencies.
- [.gitignore](.gitignore) — ignores for Python/IDE files.
